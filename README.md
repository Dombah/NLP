# NLP lab work
 
Four natural-language-processing exercises from the Data Science MSc at FERIT Osijek
(notebooks are in Croatian).
 
| notebook | topic | tools |
|---|---|---|
| `LV1_NLP_rj.ipynb` | text preprocessing and part-of-speech tagging | spaCy, NLTK |
| `LV2_NER.ipynb` | named entity recognition | spaCy |
| `NLP_LV3.ipynb` | text classification with classical ML, class imbalance | scikit-learn, imbalanced-learn, NLTK, spaCy |
| `LV4_word_embeddings_RJEŠENO.ipynb` | word embeddings and semantic similarity | gensim, scikit-learn |
 
Open any notebook on GitHub to see it with outputs, or run it locally with Jupyter.
